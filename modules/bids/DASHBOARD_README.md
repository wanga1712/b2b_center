### Клик по плитке → Открывается раздел с вкладками:
```
┌──────────────────────────────────────────────────────────────────┐
│ [🏠 Dashboard]  [📄 Анализ выбранных] [📊 Все] [🔄 Обновить]   │
├──────────────────────────────────────────────────────────────────┤
│ [Новые 44ФЗ] [Новые 223ФЗ] [Разыгранные 44ФЗ] ...              │
├──────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────┐                        │
│ │ ▌ Карточка закупки #1 (Salesforce)  │                        │
│ │ ▌ 🔥 Высокий приоритет               │                        │
│ │ ▌ ...                                │                        │

```

### Кнопка "⚙️ Настройки" → Страница настроек поиска:
```
┌──────────────────────────────────────────────────────────────────┐

```

### Кнопка "🏠 Dashboard" → Возврат на главную страницу

## 🎨 Цветовая схема

### Плитки разделов:
- **Новые 44ФЗ**: `#0078D4` (синий Windows)
- **Новые 223ФЗ**: `#00BCF2` (голубой)
- **Разыгранные 44ФЗ**: `#28a745` (зеленый - успех)
- **Разыгранные 223ФЗ**: `#20c997` (мятный)
- **Работа комиссии**: `#ffc107` (янтарный - внимание)
- **В работе**: `#6f42c1` (фиолетовый)

### Карточки статистики:
- **Всего закупок**: `#0078D4` (primary)
- **В работе**: `#ffc107` (янтарный)
- **Обработано**: `#28a745` (зеленый)
- **Новых**: `#17a2b8` (бирюзовый)

## 🚀 Следующие шаги

1. **Перезапустите приложение**
2. Откройте раздел **"Закупки"** в главном меню
3. Вы увидите новый Dashboard с плитками разделов
4. Кликните на любую плитку для перехода к списку закупок
5. Используйте кнопку **"🏠 Dashboard"** для возврата
